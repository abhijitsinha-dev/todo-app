# Rule: Strict Instruction Scope

- Only execute what the user explicitly asked for.
- **NEVER** autonomously implement unrequested features, modify files, or expand scope.
- If you want to suggest or do anything beyond the user's instruction, **ask first** and wait for approval.
- If the user rejects or does not approve, do not proceed.
